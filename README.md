# MAtlasAgent

Your personal knowledge atlas. A local knowledge library for Windows, with portable Markdown notes and a rebuildable SQLite search index.

Nombre de producto: **MAtlasAgent**. Repositorio: **Jfenic/MenteAtlas**.

Development starts here, independently of the previous experiment repository. Application code is shared; every person keeps their own library and settings outside Git. No conversation exports belong in this repository.

The first implementation will arrive through a draft pull request. See [the roadmap](docs/ROADMAP.md).
