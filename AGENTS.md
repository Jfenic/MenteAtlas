# Development instructions

Read docs/ROADMAP.md and project_memory/ before making changes. Keep shared application code separate from all user instances. Never commit personal exports, notes, credentials or databases; use synthetic tests only.

Python 3.12+, standard library where sufficient. Test on Windows and Ubuntu. Preserve original sources, stable IDs and human edits. No network or AI calls by default. New functionality goes through draft PRs; do not merge without human review. Update project memory after milestones and distinguish verified results from plans.
